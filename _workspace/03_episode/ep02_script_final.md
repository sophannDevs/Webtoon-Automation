## 읽는 법

- 패널 제목: `### P## · 샷 · 씬/장소 ⟨태그⟩`. 태그: `⟨반전⟩` `⟨이중의미⟩` `⟨ECHO:…⟩`(E# = twist-plan §2-7, F-## = series-arc 떡밥, 그 밖은 원본 패널). `↺EP01 P##` = 비트시트 §3-1의 재사용 구도
- `(…)` = 행동·연출 지시. `화자: "…"` = 한국어 작업 대사. 바로 아래 `KM:` = **독자가 보는 크메르어**(출판문). 레터링 `text_km`은 큰따옴표 안을 글자 그대로 복사한다
- KM 화자 꼬리표(독자에게 보이지 않음, letterer용): `(គិត)` 생각 · `(ការចងចាំ)` 기억/리플레이 말풍선(`type: memory`) · `(តាមទូរស័ព្ទ)` 전화 · `(តិចៗ)` 작은 소리
- `[효과음]` 아래 `KM 효과음:` · 마감 `KM 캡션:` · 물건 위 글씨(`「…」 KM:`)는 **EP02에 없다**(비트시트 §4: 수칙 종이·인수인계서·일지의 내용은 전부 낭독 말풍선. `env` 0)
- 메타 줄 `-`: 긴장 · gap(px, = 레터링 `gap_after`) · ⊘ 그림 속 빈 면 소품 · 단서 ID
- KM 문장 안에서는 큰따옴표를 쓰지 않는다(인용 속 인용은 « »). 같은 대사의 반복은 KM까지 **바이트 단위로 같다**(검수 노트 C에 일치표)
- 말풍선 예산: 패널당 대사 말풍선 1–2개(효과음 별도), 크메르어 약 2줄. 한 `KM:` 줄 = 말풍선 하나

**T-a (P1–20) 손 주인 = 남재우, 지난 루프를 기억하는 산 사람 — PASS.** 처음 읽는 독자 기준 흐름: EP01 클리프 리캡(P1, EP01 P62·P63과 바이트 동일) → 소매를 타고 오르는 컷(P2, 빈 목줄) → 얼굴(P3: 정상 그림자, 마른 옷, 반만 빛) → «…លោកជានរណា?»(P4) → «ឯងធ្វើតាមច្បាប់ទី៤ទៀតហើយ ត្រូវទេ?»(P5: 그는 그녀를 안다) → 서하가 `ទៀតហើយ`만 되받고 그는 `ឯង` → `អ្នក`로 물러선다(P6: 그녀는 그를 모른다) → E11 인셋 `ឈប់`과 그의 `រត់ចោល`(P8–9: 전임자) → «មិនមែនកណ្ដុរទេ។ គឺគ្នាទេតើ។»(P10: EP01 '쥐' 회수) → 마른 운동화 + «…លោកជាមនុស្សឬ?» / «…សម្រាប់ពេលនេះ។»(P12–13: 사람이다, 지금은). 독자의 예측(손 주인 = 4번을 덧댄 자)은 P16 질문으로 정면 제기되고 P17 가정형 «បើគ្នាជាអ្នកបិទ គ្នាបកវាចេញយូរហើយ។»(법칙 ⑥)으로 뒤집힌다. 테이프의 목적은 P20 «…លើកមុន ឯងចង់បិទពីលើវា។ ទើបគ្នាយកស្កុតមក។»로 닫힌다(덮으러 가져왔다). 너무 빠르지 않다(P2 gap 480, 얼굴 → 이름 없는 정체 → 사람 확인이 13컷에 걸침), 모호하지 않다(얼굴 + 대명사 비대칭 + 인셋 둘 + 마른 바닥). 누가 4번을 덧댔는지는 끝내 말하지 않는다(EP19 보호). 대가: 첫 «ទេ។»(P22) + F-26 약속, 거짓 4번은 그대로.

**T-b (P27–41) 05:59 "퇴근하세요" = 인수인계 제안, 수칙 7 역전 — PASS.** 예측(괴이의 유혹) 쌓기: 7번 첫 낭독(P27, b4 · 06:00 타이머) → 선임 "그 줄만 기억하래" + 서하 생각 «…អ្នកណាធ្លាប់ប្រាប់ខ្ញុំ ឱ្យចេញពីធ្វើការ?»(P28, m1) → 계단 발소리(P30, b3 ← P25 «គ្នានឹងនៅឯជណ្ដើរ។») → 공손한 `អ្នក`/`ខ្ញុំ` 목소리(P31–33, m2) · 눈 감은 선임(m3) · 형광등 떨림 없음(b5, 공정한 신호). 공개: 얼굴 + 대명사가 `គ្នា`로 돌아옴 + P15 주머니의 이중 테두리 서류(b1)(P34). 정점: 서식 마지막 줄이 수칙 7의 동사로 끝난다 «…អ្នកប្រគល់វេន ចេញពីធ្វើការ។»(P35) → «ពាក្យប្រាប់ឱ្យចេញពីធ្វើការ… គឺពាក្យសុំនៅជំនួស។»(P36: v4부터 수칙 7 둘째 문장의 구와 글자 하나 같다. `ពាក្យ` = 말/신청) → P27 리플레이 인셋 + «ច្បាប់ទី៧… គឺដើម្បីការពារអ្នកដែលព្រមទទួលជំនួសខ្ញុំទេតើ។»(P37, gap 720). 동기 P38(«ព្រោះគ្នារត់ចោល…» = P9 동사), 대가 P39 «ទេ។»(P22와 바이트 동일, 유일한 출구를 스스로 닫음), 근거 P40(열쇠 기록과 일치 + 의지 = 안전). 한 동사 `ចេញពីធ្វើការ`가 수칙·목소리·서식·깨달음·거절·06:00을 관통하므로 크메르어 독자도 "같은 말이 뜻을 바꿨다"를 말에서 본다. 너무 빠르지 않다(목소리 → 공개 4컷, P33 gap 480), 모호하지 않다(생각 P36 + 리플레이·해설 P37 이중 확인).

### D. 번역 질문 결정 (glossary_km v4 메모 열에 같은 내용)

- **(a) 수칙 7 둘째 문장 → 늘림 (확정).** 먼저 확인: 수칙 7의 KM은 `ep01_script_final.md`(와 `ep01_lettering.md`)에 없다 — EP01 비공개 조항이라 출판된 적이 없다. 그래서 고정 문구를 «ទី៧។ មុនម៉ោង៦ព្រឹក មិនត្រូវចេញពីធ្វើការឡើយ។ ទោះអ្នកណាប្រាប់ឱ្យចេញពីធ្វើការក៏ដោយ។»로 바꿨다(glossary §6, 이 대본 P27 ②·P37 기억). 이유는 A표.
- **(b) 수고했어(요) = `នឿយហត់ហើយ` (확정).** "고생했다/지쳤겠다"를 알아주는 크메르어 구어 인사로 자연스럽고, 짧아서 두 컷(P31 «អ្នកនឿយហត់ហើយ។» · P53 «នឿយហត់ហើយ អូន សឺហា។»)의 핵심 구가 그대로 반복된다. 대안 `អរគុណដែលខំប្រឹង`은 "애써 줘서 고마워"라 상사의 치하에 가깝고 계단 목소리(동료의 위로)에는 맞지 않으며, 두 컷 에코도 길어진다.
- **(c) "아직은." = `…សម្រាប់ពេលនេះ។` (유지).** 크메르어에서 이중 의미(지금은 사람 / 나중엔 아니다)가 가장 선명한 형태다. `នៅ…នៅឡើយ` 계열로 F-24 «នៅមិនទាន់…»의 '아직'과 낱말을 잇는 안은 단독 답으로 어색하거나(«…នៅឡើយ។») 길어져 사실 단정(«នៅជាមនុស្សនៅឡើយ។» "아직 사람이다")이 된다. 한국어 '아직'의 F-24 연결은 한국어 쪽 울림일 뿐 단서 사슬이 아니다(F-24의 회수는 P20 «…លើកមុន ឯងចង់បិទពីលើវា។»가 맡는다). EP10 회수는 `សម្រាប់ពេលនេះ`를 그대로 쓴다.
- **(d) 인수자 `អ្នកទទួលវេន` / 인계자 `អ្នកប្រគល់វេន`, 테이프 `ស្កុត` (확정).** 캄보디아 행정의 인수인계 문서(កំណត់ហេតុប្រគល់-ទទួល)는 서명란을 흔히 `អ្នកប្រគល់`/`អ្នកទទួល`로 적고, 여기에 `វេន`을 붙여 당직 인수인계 `ការប្រគល់វេន`·인수인계서 `លិខិតប្រគល់វេន`과 짝을 맞췄다. 담당자 `អ្នកទទួលបន្ទុក`와 `អ្នកទទួល…`이 겹치는 것은 EP03(인수인계서가 담당자 지위까지 넘긴다)에 유리하므로 그대로 둔다 — 단 두 말을 바꿔 쓰지는 않는다. `ស្កុត`은 접착테이프를 부르는 가장 흔한 구어(대사 P16·P20), 소품 이름 `ស្កុតក្រហម`.
- **(e) 노미란의 낮 "서하 씨" = `អូន សឺហា` (확정, 장면이 정당화한다).** EP01에서 그녀가 쓴 풀네임 `មន្ត្រី កាង សឺហា`는 당직실(관할) 안에서 서하의 이름을 기록에 올리는 장치(F-10)였고, `កញ្ញា សឺហា`는 겁먹어 대명사가 무너진 순간(P47)이었다. P53·P56은 06:00 이후 관할 밖, 그리고 **다시 떠넘기는 장면**이다. characters §3-3은 그녀의 떠넘김을 `បង`(자신)/`អូន`(서하)의 가짜 친밀로 설계했고, EP01 P9 «…មានឈ្មោះបង។»에서 이미 `បង`을 썼다. 그러므로 `អូន`은 새 말투가 아니라 EP01 말투의 짝이 처음 드러나는 것이며, 밤의 차가운 직함(`មន្ត្រី`) → 겁먹은 `កញ្ញា` → 낮의 `អូន`의 변화가 그대로 권력 회복을 보여 준다. P56이 EP01 P8 구도(COMP-HANDOVER)를 되풀이하는 대구는 꼬리 «…មែនទេ?»(P57)가 맡는다. 서하는 계속 `ប្រធានក្រុម`.
- **(f) 효과음 `គ្រេត—`(P2 회전의자) · `ធឹប… ធឹប…`(P30 계단 발소리) · `ក្រឹក!`(P44 방화문 밀대) · `វឺ… វឺ…`(P44 휴대폰 진동) (확정).** 각각 `គ្រេតៗ`(삐걱)·`ដើរធឹបៗ`(쿵쿵 걷다)·`ក្រឹក`(걸쇠·자물쇠 딸깍)·`ញ័រវឺៗ`(웅웅 떨다)의 소리말로 익숙하다. `ក្រឹក!`은 22:00의 `ផាំង!`(EP01 P7·P28)과 일부러 다른 소리(06:00 문을 연다). EP01 효과음처럼 원어민 최종 감수 때 한 번 더 들어 볼 목록에 남긴다.
