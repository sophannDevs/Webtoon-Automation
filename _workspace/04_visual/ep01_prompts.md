- Order inside each prompt: shot and action with each character ("matching the attached reference image" + identity keywords + expression), props (anything that could carry writing is blank), one fixed place sentence per location (identical inside a scene; a short soft-focus variant for close-ups), the scene's light sentence, the reserved-lilac sentence (P08, P16, P29, P50 only), the empty-area sentence, the style sentence, `No panel borders.` (not on P23, the three-strip panel), and the Avoid line. No token names, file paths, dialogue or bubble sentences inside any prompt.
- The main character of a panel gets the long identity keywords, the others a short form; the attached reference sheets carry the rest. Word count: 180–311 per prompt, average 246 (the fixed style sentence alone is 66 words; the longest are the crowded wide shots P05 and P13).
- Every prompt ends with `Avoid: any text, letters, numbers, writing, speech bubbles, captions, watermark.`
- Lady Min's jacket is always `deep wine-red plum ... NOT purple`. Pale lilac appears only in P08, P16, P29, P50; no other prompt contains a lilac word.
