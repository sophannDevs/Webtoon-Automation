## 읽는 법

- 패널 제목: `### P## · 샷 · 씬/장소 ⟨태그⟩`. 태그: `⟨반전⟩` `⟨이중의미⟩` `⟨ECHO:E#⟩`(twist-plan §2-7 번호)
- `(…)` = 행동·연출 지시. `화자: "…"` = 한국어 작업 대사. 바로 아래 `KM:` = **독자가 보는 크메르어**(출판문). 레터링 `text_km`은 큰따옴표 안을 글자 그대로 복사한다
- KM 화자 꼬리표(독자에게 보이지 않음, letterer용): `(គិត)` 생각 · `(ការចងចាំ)` 기억/리플레이 말풍선(`type: memory`) · `(តាមទូរស័ព្ទ)` 전화 · `(សំឡេង)` 화면 밖 목소리 · `(ខ្សឹប)` 속삭임 · `(តិចៗ)` 작은 소리 · `(ព្រមគ្នា)` 동시
- `[효과음]` 아래 `KM 효과음:` · 마감 `KM 캡션:` · 물건 위 글씨(`「…」 KM:`)는 **EP01에 없다**(문서 내용은 전부 낭독. 수칙 종이에 `env` 금지)
- 메타 줄 `-`: 긴장 · gap(px, = 레터링 `gap_after`) · ⊘ 그림 속 빈 면 소품 · 단서 ID
- KM 문장 안에서는 큰따옴표를 쓰지 않는다(인용 속 인용은 « »). 같은 대사의 반복은 KM까지 **바이트 단위로 같다**(검수 노트 C에 일치표)
- 말풍선 예산: 패널당 대사 말풍선 1–2개(효과음 별도), 크메르어 약 2줄. 한 `KM:` 줄 = 말풍선 하나

### 화자 · 말투 (KM)

| 한국어 화자 | KM 화자 | 크메르어 말투 |
|---|---|---|
| 서하 | សឺហា | 직장: `ខ្ញុំ` + `ចាស`, 최고 격식. 루프 1에만 반사적 `សុំទោស`. 루프 2: 짧고 평평, `ទេ`로 끊는다. 절차를 말할 때만 길고 정확(행정 문어). 선임은 `លោកពូ`, 노미란은 `ប្រធានក្រុម`. 지호에게는 자신 `បង` |
| 노미란 | ណូ មីរ៉ាន | 자신 `បង`, 서하는 풀네임 `មន្ត្រី កាង សឺហា` / 꼬리 `មែនទេ?` `ណា៎?`. 겁먹으면 `ខ្ញុំ` · `កញ្ញា សឺហា`로 무너진다 |
| 선임 | លោកពូ | 아주 짧다. 서하를 `ឯង`으로만, 자신은 `ខ្ញុំ`. 이름은 아무도 부르지 않는다. 밤·수칙에 관한 말은 전언 `គេថា …`(= "~래")로만 |
| 구정민 | គូ ជុងមីន | `សូមទោស`·`បាទ`, 행정 문어, 감정 어휘 없음. 반복 대사는 글자 하나 바꾸지 않는다 |
| 지호(전화) | ជីហូ | 빠른 구어, 누나는 `បង`, 첨사 `ណា៎`, 의문 꼬리 `អត់?` |
| 목소리(뒤) | សំឡេងពីក្រោយ | 가볍고 다 아는 듯한 구어 |

### B. 반전 명료성 판정 (twist-patterns §4 체크리스트 + twist-plan §2-9)

**반전 1 (P22–30) — PASS.** 처음 읽는 독자 기준 흐름: 수칙대로 «ខ្ញុំជាអ្នកទទួលបន្ទុក។»(P23) → «អ្នកដែលគ្មានឈ្មោះក្នុងបញ្ជីវេន… ជាអ្នកទទួលបន្ទុកឬ?» + P9 인셋 «ក្នុងបញ្ជីវេន មានឈ្មោះបង។»(P24: 왜 틀렸는지가 같은 컷에서 보인다) → 떨림·어둠·빈 의자(P25–27, 죽음은 화면 밖) → P7과 같은 구도·같은 «ផាំង!»(P28: 되감김) → 끝인사만 기억(P29) → 약속 상실(P30). P32에서 노미란 대사가 글자 그대로 반복되고 서하가 «មែនទេ?»를 함께 말해 "루프"가 두 번 확인된다. 너무 빠르지 않다(P27 720px 정지), 모호하지 않다(앵커 + 반복 대사 + 약속 상실 3중). 대가(약속)와 다음 엔진(4번 거부)이 선다.

**반전 2 (P50–57) — PASS.** 시각 정점 P53(같은 큰 왼쪽 귀) → 물적 사슬 P54 + «មានតែតុនេះ… ដែលមិនវិលទៅក្រោយ។»(책상만 되감기지 않는다는 규칙을 말로 한 번 묶어 크메르어 독자의 추론을 받친다) → 대사 정점 P55(P21 인셋과 같은 문장 + «…គឺខ្ញុំទេតើ។»). 앞선 단서: P5 «មានតែមួយគត់ក្នុងលោក»·P1/P19 바랜 스티커·P12 입 모양·P31 수칙 모양의 속마음 «ទី១។ … ឡើយ។»·P33 영수증 높이·P50 «ម៉េចក៏ចាំលំដាប់ច្បាប់បាន?». 미스디렉션(선임: P18·P22·P37 «គាត់… ដឹងរឿងនេះ។») → P50 빈 접이식 의자로 해제. 금지 준수: "전부 내가 썼다"·"4번은 안 썼다" 없음, 4번은 질문 «ចុះ… ច្បាប់ទី៤វិញ?»뿐. 동기 암시 P57.

**클리프 (P58–64) — PASS.** 소리 → 그림자 → 손(은반지·차콜 소매 = 선임 아님) → «ច្បាប់នោះ…»(P21과 같은 첫 구절, 다른 목소리) → «នៅមិនទាន់ប្ដូរទៀតទេ?» → 무대사 최종 컷. 가리는 것은 얼굴 하나.

- 주의(연출 쪽, 대본 변경 없음): 반전 1이 서려면 P28 시계 바늘(10시 정각)과 방화문·토트백이 P7과 **똑같이** 그려져야 한다. 반전 2는 P53의 "큰 왼쪽 귀"와 P54의 뜯긴 제본 가장자리가 클로즈업에서 분명히 보여야 한다. 둘 다 글씨 없이 성립한다.

### D. 번역 질문 결정 (glossary_km v2 메모 열에 같은 내용)

1. **선배님 = `លោកពូ` (확정).** 25세 신입이 50대 후반 남성 동료를 부르는 자연스러운 존칭은 "아저씨" 계열이다. `បង`은 10년 안팎 연상에게 쓰는 말이라 이 나이 차에서는 어색하다. 자신은 `ខ្ញុំ`(직장 격식).
2. **선임의 `ឯង` (유지).** 나이 많은 남자가 한참 어린 동료에게 쓰는 무뚝뚝한 반말로 자연스럽고, 욕이나 모욕은 아니다. 짝이 되는 거친 `អញ`은 쓰지 않고 자신은 `ខ្ញុំ`. `ក្មួយ`(정이 묻음)·`អ្នក`(남남 같은 거리)는 쓰지 않는다. 그래서 거칠지 않고 "정을 주지 않는" 선에 머문다.
3. **시각 = 12시간제 + 때를 붙인다: `ម៉ោង១០យប់` / `ម៉ោង៦ព្រឹក` (확정).** 캄보디아 공문·안내문도 "ម៉ោង … ព្រឹក/ល្ងាច/យប់" 형식을 쓰고 독자에게 가장 자연스럽다. 24시간 표기는 쓰지 않는다. 크메르 숫자, 붙여 쓰기.
4. **사망신고 = `ការចុះបញ្ជីមរណភាព` (확정).** 캄보디아 호적(អត្រានុកូលដ្ឋាន) 용어 체계의 "출생 등록/사망 등록"과 같은 꼴이다. 그 결과 문서인 사망증명서는 `សំបុត្រមរណភាព`(EP01 대사 없음, 메모로만 등록).
5. **효과음:** `ផាំង!`(문)·`ទីង!`(벨)·`តក់!`(물방울)·`ភ្លឹប… ភ្លឹប—`(형광등 깜빡임)·`ក្ដុក!`(노크)·`ព្រែត—`(테이프 뜯기)는 유지. 부스럭은 `ស្រុកស្រាក់…` → **`ក្រុបក្រាប…`**로 바꿈.
6. **수칙 1 첫 말풍선: 고정 문구를 줄였다.** glossary §6 수칙 1, P12 ①, P35를 같은 문자열로 바꿨다(위 A표). 넓은 말풍선이 따로 필요 없다.

### E. letterer · panel-director 권고

- 말풍선 수: P13·P34·P36 = 대사 2 + 효과음 1, P48 = 2(새로 나눔), 나머지 ≤ 2. 한 `KM:` 줄 = 한 말풍선.
- 줄 수 실측(뷰어와 같은 말풍선 CSS, Battambang과 대체 글꼴 Khmer UI 둘 다): **w 60%면 모든 말풍선이 2줄 이하.** w 50%로 좁히면 3줄이 되는 것: P12 ①·P35(두 글꼴), P9 ①·P21·P55 ①·P49 ①(Khmer UI). 이 다섯 줄은 w 60% 이상으로 받는다. 짧은 줄(P2·P23·P32 ② 등)은 w 30–40%로 충분하다.
- 크메르어 줄바꿈은 띄어쓰기 자리에서 일어난다(뷰어 `word-break: keep-all`). 대본의 띄어쓰기는 구 경계에 일부러 둔 것이니 `text_km`에서 지우거나 더하지 않는다.
- 기억 말풍선(`type: memory`): P24 ②, P29, P52, P55 ①. 생각(`thought`): P22 ②, P31, P37 ②, P54, P57 ①. 화면 밖 목소리 꼬리: P19, P45(프레임 가장자리), P62·P63(위쪽 밖).
- P53 서하 말풍선은 아주 작게(2분할 클로즈업의 경계선 위), P32 서하 «មែនទេ?»는 노미란 말풍선 끝에 겹치게.
- 원어민 최종 감수 권장 지점(대본은 그대로 넘겨도 된다): 효과음 `ក្រុបក្រាប`·`ព្រែត`·`ភ្លឹប`, 노미란의 `មន្ត្រី កាង សឺហា`(한국 직급 '주무관'의 직역이라 약간 관공서 냄새가 나는데, 의도와 맞다).
