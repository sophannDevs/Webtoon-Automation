- **태오(풍선 19):** 모두 「។」로 끝나는 평서문. !·? 0, ពពក 0, 젖은 이유·날씨 질문 0(P07 「ម៉ោងបីរសៀល។ ភ្លៀងមួយមេ។」은 그녀가 아니라 시내 비 예보), 감정어·명령형·소유형 0, 구어 조사(ណា៎·ទេតើ·ហ្នឹង·ៗ) 0, អ៊ីចឹង은 P12 인용 틀 하나뿐(§7 예외). 숫자·사물: ទីពីរ, ម្ភៃប្រាំឆ្នាំ, ម៉ោងបួនដប់នាទី, ពីរដង, តំណពីរកន្លែង, ម៉ោងបីរសៀល, ឆ្អឹងពីរ, ឃ្លាខ្លីមួយ, ចំណតឡានក្រុង. 대답 「បាទ។」(P46), 웃음 「…បាទ។」(P59). 거짓 0: P36·P41·P43 모두 참말.

### 6. 플래그 (leader / script-editor)

1. **P43 「별말 아니었어요」의 KM은 한국어 표면 뜻('대단한 말 아니었다')보다 좁다.** 참말 조건(twist-plan §4)을 우선해 '짧은 한 문장'으로 썼다. 독자에게는 얼버무림 + 숫자 말투로 읽히고, P44 「បើខ្លី…」가 받는다.
2. **P11 흉내에 « »를 쓰지 않았다**(EP1 P31 선례). 비트시트 §5는 « »를 제안했다. 에디터가 « »를 원하면 KM은 「«ម្ភៃប្រាំឆ្នាំ។»」로 바꾸면 되고 다른 줄은 영향 없다.
3. **「다신 안 와요」 = «ខ្ញុំលែងមកទៀតហើយ។»** 를 이번에 고정했다(D2 오후 4:10, 화면 밖 발언 · 리더 판정 UD). 이후 회차 인용은 이 « » 안을 글자 그대로.
4. **할머니의 이름 없는 화자 표기 យាយ / 손님 ភ្ញៀវ** 를 glossary §8-1에 올렸다(km_review 화자 점검 통과). 할머니 대사의 한국어 호칭은 「총각」으로 통일(P17).
5. **ID:** 새 고정 문구 F20–F31. 효과음 S02·캡션 C01은 EP1 ID를 그대로 다시 썼다(같은 소리 · 같은 형식, 숫자만 ៣).
6. EP1 파일은 건드리지 않았다. glossary는 §8 덧붙임만(§0–§7 변경 0, git diff로 삭제 줄 0 확인).
