## 2. 주요 인물

### 2-1. 한서윤 (17, 여, 2학년 1반): 여주인공

**역할:** 시점 인물. 계약의 제안자이자 정보의 을. 서진 장학생 내정자(2위, 1위 거절로 순번이 내려옴).

**성격:** 단정하고 빠르다. 말도, 필기도, 계산도. 남의 부탁은 다 들어주지만 자기 부탁은 하나도 안 한다. 규칙을 정확히 알고, 그래서 규칙의 빈틈도 정확히 안다. 긴장하면 손에 잡히는 종이(껌 포장지, 영수증, 쪽지 귀퉁이)로 작은 종이학을 접는다. 본인은 버릇인 줄 모른다.

| 항목 | 내용 |
|---|---|
| **원하는 것 (want)** | 기말 성적 발표일까지 장학 자격 유지(3위 이내 + 위반 기록 0). 다시 전교 1등. 그리고 누구에게도 동정받지 않는 것 |
| **진짜 필요 (need)** | 들키는 것과 동정받는 것은 다르다는 걸 배우는 것. "알려진 채로" 곁에 사람을 두는 것 |
| **치명적 결함** | 자존심이 도움을 막는다. 문제가 생기면 혼자 더 큰 거짓말로 덮는다(엄마에게, 학교에, 도하에게). 주도권을 쥐어야 안심하는 통제 욕구 |
| **두려움** | 가난이 "구경거리"가 되는 것. 엄마가 자기 때문에 더 무리하는 것. 사장님을 다치게 하는 것 |
| **비밀** | ① 솔내동 24시 편의점에서 매일 22:00~01:00 혼자 근무(현금, 근로계약서 없음). ② 집은 솔내동 오르막 골목 끝 반지하 단칸방. ③ 엄마에게 "야자 후 학원가 24시 독서실에서 1시까지 공부한다", "장학생은 생활지원금이 매달 나온다"고 거짓말 중(알바비가 그 '지원금'). ④ 9년 전 겨울의 소년을 기억하지 못한다(본인도 모르는 빈칸) |
| **가족** | 엄마 정혜원과 둘. 아빠는 슈퍼가 문 닫은 뒤(서윤 10세 무렵) 빚을 남기고 집을 나갔고 이후 연락이 끊겼다. 서윤은 아빠 얘기를 먼저 꺼내지 않는다. (남색 점퍼 남자와의 연결은 정하지 않는다. W5) |
| **하루** | 06:30 기상 → 수업(오후에 꾸벅임) → 야자 → 21:40 종 치자마자 뛰어 21:44 버스 → 21:58 창고에서 조끼 → 01:00 퇴근 → 01:15 귀가. 잠 5시간 남짓 |
| **아크 (시즌 1)** | "아무도 몰라야 해" → (도하가 다 알았다는 충격) → "아는 사람 앞에서도 무너지지 않는 법" → 처음으로 누군가에게 먼저 "도와줘"라고 말한다. 조항 6("먼저 진심이 되는 쪽이 진다")을 스스로 깨는 쪽이 서윤이면, 그때 털어놓는 비밀은 가난이 아니라 "나 너 기억 못 해서 미안해"다(제안, 확정은 series-plotter) |
| **ep01 동선** | 콜드 오픈 계산대 → 첫 2등 → 복도에서 도하에게 따짐 → 계단참 계약 제안 → 반 공개 → 하람의 가방 검사를 규정으로 반격 → 밤 편의점 → 마지막 대사에 얼어붙음 |

**말투 시그니처 (한국어):**
- 또래에게 반말, 빠르고 완결된 문장. 논리로 몰아붙일 때 "첫째, 둘째, 셋째"로 센다. 숫자와 규정을 정확히 인용한다: "소지품 검사는 담임 입회. 본인이 직접 열고. 둘 다 아니잖아."
- 궁지에 몰리면 문장이 짧아지고 화제를 끊는다: "됐어.", "내 일이야.", "신경 꺼."
- 고맙다는 말을 못 해서 다른 말로 돌린다: "…오답노트 내일 줄게."
- 편의점 계산대에서는 완전히 다른 사람, 기계적인 서비스 존댓말: "봉투 필요하세요?", "이건 오늘까지예요."
- 도하를 늘 풀네임으로 부른다: "백도하." (거리 두기. 이름만 부르는 순간이 시즌의 이정표)
- 금지: 울먹이는 장문 신세 한탄. 서윤은 약한 소리를 길게 하지 않는다.

### 2-2. 백도하 (17, 남, 2학년 1반): 남주인공

**역할:** 2학기 전학생. 첫 시험(2학기 중간)에서 전교 1등. 장학금을 거절해 순번을 서윤에게 내려보낸 사람. 계약의 을처럼 보이지만 정보의 갑.

**성격:** 말이 짧고 표정 변화가 적어 무심해 보이지만 관찰력이 비정상적으로 좋다(사람의 손, 버릇, 시간을 본다). 농담은 무표정으로 한다. 진지할수록 말이 더 짧아진다. 질문에 질문이나 관찰로 답한다. 남이 숨기는 걸 알아도 먼저 말하지 않는다.

| 항목 | 내용 |
|---|---|
| **원하는 것 (want)** | 표면: 조용히 학교 다니기. 실제: 서윤 곁에 있되, 동정으로 보이지 않는 방식으로. 그리고 그녀가 언젠가 스스로 그 겨울을 떠올려 주는 것 |
| **진짜 필요 (need)** | "아는 것"으로 사람을 지키는 게 아니라, 알고 있다는 걸 털어놓고 상대가 고르게 두는 것. 기억해 주길 기다리는 게 아니라 지금의 자기로 다시 알려지는 것 |
| **치명적 결함** | 정보를 쥐고 남 대신 결정한다(말없이 장학금을 거절한 것이 그 예. 서윤이 가장 싫어하는 "몰래 베푸는 배려"를 그가 하고 있다). 진심을 들키느니 침묵을 고른다 |
| **두려움** | 잊히는 것(이미 한 번 잊혔다). 서윤이 자기를 "불쌍해서 도와주는 애"로 보는 것. 자기 집안 사정이 그녀를 다치게 하는 것(W6, 비공개) |
| **비밀 (겹)** | ① 서윤의 야간 근무를 전학 전부터 알았다(ep01 끝 공개). ② 9년 전 겨울 동네 슈퍼 앞 빨간 의자의 "학 소년"이다. 그때 이름은 김도하. 부모 이혼과 엄마의 재혼 뒤 새아버지 성으로 바뀌었다. ③ 장학금 거절의 진짜 이유(W2, 여기서 정하지 않음). ④ 왜 전학 왔는지, 밤마다 어디서 걸어오는지(W4, 정하지 않음) |
| **9년 전의 비대칭** | 여덟 살 도하는 자기 이름을 말한 적이 없다. 서윤은 그를 "안경"이라고 불렀다. 도하는 슈퍼 안에서 엄마가 부르는 "서윤아" 소리로 그녀의 이름을 알았다. 그래서 **도하만 이름을 안다.** |
| **가족** | 엄마와 새아버지(사업가, 업종·회사 비공개: W6 우물을 닫지 않는다). 형제 없음. 돈 걱정은 없지만 집 이야기를 하지 않는다 |
| **공부** | 진짜로 잘한다. 조항 5(일부러 져 주면 즉시 파기) 때문에 서윤과의 등수 전쟁에서 봐주지 못한다. 그것이 그의 손발을 묶는다 |
| **아크 (시즌 1)** | "곁에서 몰래 지킨다" → (계약으로 공식적인 곁을 얻는다) → 그의 몰래 한 배려가 서윤의 자존심을 다치게 한다는 걸 정면으로 맞는다 → 아는 것을 하나씩 내려놓고 "기억 못 해도 괜찮아, 지금부터 알면 돼"로 간다 |
| **ep01 동선** | 콜드 오픈 후드 손님(얼굴 안 보임) → 호명된 1등 → 복도 티키타카("아직도 이런 거 접어?" 말실수) → 계단참 "어젯밤 거기, 너지?" → 계약 대가 "오답노트 전부. 그리고 일 끝나면 연락해." → 매점에서 기한 짧은 빵 고름 → 가방의 레진 학 키링 → 마지막 대사 |

**말투 시그니처 (한국어):**
- 1~6어절. 마침표가 많다. 감탄사가 거의 없다. "봤어.", "그래서?", "싫은데.", "알았어."
- 서윤을 늘 풀네임으로: "한서윤." (그가 이름을 부르는 방식 자체가 9년 묵은 것)
- 무표정 개그: "…방금 1분 동안 세 개 접었잖아."
- 사과 대신 사실을 말한다: "미안" 대신 "내가 늦었네."
- 중요한 순간에만 문장이 길어진다. 그래서 긴 대사 한 줄이 반전이 된다: "어젯밤에 안 거 아니야. 처음부터 알았어, 한서윤. 네가 나 기억 못 하는 것까지."
- 금지: 능글맞은 플러팅, 재벌식 명령조("내 여자"), 돈으로 해결하는 제안.

**성격:** 원칙주의자. 등이 곧고 걸음이 빠르다. 규칙을 지키는 게 공정이라고 진심으로 믿는다. 융통성이 0이고, 규정을 외우긴 하는데 해석을 가끔 틀린다(ep01에서 소지품 검사 절차를 어기는 것이 그 결함의 첫 노출). 칭찬에 약하고, 틀렸다는 걸 인정하는 데 한 박자 걸린다.

| 항목 | 내용 |

| **원하는 것 (want)** | 서진 장학생 자리. 서윤이 자격을 잃으면 순번은 자기다. "정당하게" 갖고 싶다 |
