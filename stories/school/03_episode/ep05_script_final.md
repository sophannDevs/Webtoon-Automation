### 5. 용어·표기 근거 (작가 노트에서 옮김, 리뷰어 참고)
- **안경 = វ៉ែនតា(사물·회차 제목) / 별명 "안경" = អាវ៉ែនតា.** អា-는 아이들끼리 붙이는 반말 별명 접두라 8세 서윤이 붙인 별명으로 자연스럽다. 사물 낱말 វ៉ែនតា를 그대로 품어 회차 제목 «វ៉ែនតា»와 P65 «អាវ៉ែនតា»가 같은 말로 묶이고, 따옴표 덕에 호칭으로 읽힌다. ep06 P1 "…안경?" = «…អាវ៉ែនតា?».
- **본인 신고 = ប្ដឹងខ្លួនឯង / 자수 = សារភាពខ្លួន**(ep04 P54). 태민은 សារភាពខ្លួន, 하람 P21과 건우 P26은 같은 ប្ដឹងខ្លួនឯង → "그게 그거잖아" 개그가 두 낱말 차이로 산다. 리뷰어는 둘을 하나로 합치지 말 것.
- **첫 번째 제보 = សំបុត្រដំបូង**(ep04 P59), **첫 번째로 넣은 사람 = អ្នកដាក់សំបុត្រដំបូង**, **학 모양 = រូបក្រៀល**.
- **녹화 = វីដេអូថត**, 30일 = ៣០ថ្ងៃ, **합의 = ព្រមព្រៀងគ្នា**, **숙제 = កិច្ចការផ្ទះ**, **남자친구 = សង្សារ**(ep03), **단골 = ភ្ញៀវប្រចាំ**(ep02), **현장 = ទីកន្លែងផ្ទាល់**(ep04 P49), **보고 = រាយការណ៍ជូនគ្រូបន្ទុកថ្នាក់**, **기록 = កំណត់ត្រា**.
- **"네 맘대로" = សម្រេចតាមចិត្តឯង**(ep04 P9 동사 그대로, P29). P31 "네가 정했어?" = សម្រេចម្នាក់ឯង.

- **오늘까지:** P57 មួយនេះ ផុតកំណត់ថ្ងៃនេះ។ = ep01 P03 서윤 "이건 오늘까지예요."에서 업무 존댓말 ចាស만 뺀 같은 문장. P60은 그 부정형. 버려 = បោះចោល.

### 6. 권고 (비주얼팀)
- **P14 도하의 쪽지는 평평한 사각**(네 번 접힘), 학 모양으로 그리지 말 것. P22 인셋의 첫 제보 쪽지는 서툰 학 모양, 두 특징 없음. P17~19 쪽지 안쪽은 각도로 가리고 무지.
- **두 특징(갈고리 머리 + 한 번 접어 내린 꼬리 끝)**은 P08·P09·P51·P59·P60에서 판별 가능한 크기로. P33은 흐리게(미디엄). P51 ↔ P60 같은 각도(매치 컷).
- **P37~38 ↔ P56 매치 컷:** 김 서린 동그란 렌즈, 소매가 덮은 손. 8세 도하의 눈은 끝까지 보이지 않는다.
- **D링:** P50 이후 도하 백팩 왼끈 D링은 비어 있음(P64 포함).
- **사장님·도하 같은 프레임은 P43부터 허용**(그 전 ep02~04는 금지였음). P47 사장님의 긴 시선.
- 회상(P53~61)은 호박색·첫눈, 현재 11월 밤엔 눈·입김 없음(안경 김 서림만).
