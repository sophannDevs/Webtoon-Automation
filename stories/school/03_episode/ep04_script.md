- **학생부장 = ប្រធានកិច្ចការសិស្ស**, **학생부실 = ការិយាល័យកិច្ចការសិស្ស**(같은 어근, P04 ↔ P54가 이어지게). 학생부장은 화면에 나오지 않는다(무대사 인물, 직함만).
- **결재 = ការអនុម័ត**, **월요일 1교시 = ថ្ងៃច័ន្ទ ម៉ោងទី១**, **출석 번호(순) = (តាម)លេខរៀង**, **체크 = គូសធីក**(កត់ត្រា "기록"과 겹치지 않게 일부러 피함: 기록은 이 시리즈에서 서윤의 생명줄 단어).
- **조끼 = អាវកាក់**(편의점 초록 조끼), **블레이저 = អាវធំ**, **단추 = ឡេវ**, **화장실 = បន្ទប់ទឹក**, **교무실 = បន្ទប់លោកគ្រូ**, **현장 = ទីកន្លែងផ្ទាល់**, **자수 = សារភាពខ្លួន**, **노트 = សៀវភៅ**.
- **P41 "낮이니까" = ឥឡូវពេលថ្ងៃ.** ep02 P38의 "지금은 낮이야" KM은 ថ្ងៃត្រង់(한낮)이었다. 이번은 1교시 뒤 오전이라 ថ្ងៃត្រង់는 틀린 시각이 된다. 조항 3의 대립은 "밤 10시 이후(យប់)"와 "낮(ពេលថ្ងៃ)"이므로 ពេលថ្ងៃ로 두었다. 리뷰어는 ថ្ងៃត្រង់로 "맞추지" 말 것.
- **P40 "고맙다곤 안 해" = ខ្ញុំមិនអរគុណទេណា។** ep03 P52와 글자 그대로 동일.
- **P06 "안 한다고 했잖아"**는 ep03 P25 ខ្ញុំមិនកុហកទេ를 품은 ខ្ញុំប្រាប់ហើយថា ខ្ញុំមិនកុហក។ → P05 서윤 កុហក와 같은 낱말로 맞받는다.
- **P49 솔내동 사거리 = `ផ្លូវបួនមុខ សុលនែដុង`** ep03 P07·P32·P51·P60과 같은 글자.
- **P47 "백도하 씨" = មិត្ត ប៉ែក ដូហា**(용어집 "한서윤 씨 = មិត្ត ហាន សឺយូន"과 같은 틀). 하람은 이 회차 내내 근무 중 공문 존댓말, 반말 없음. 담임에게만 ចាស(P02, ep03 리뷰 결정 유지), 또래에게는 어말 첨사 없음.
- **호칭·말투:** 서윤 ↔ 도하 ខ្ញុំ/ឯង, 서윤 → 담임 앞 ចាស(P30·P32, 담임 입회 중의 말), 도하 → 담임 បាទ(P36), 도하 → 하람 첨사 없음(P48), 태민 → 담임 លោកគ្រូ…បាទ, 담임 → 학생 풀네임·គ្រូ. 도하 "응" = អឺ(ep02 P05 검토본).
- **P35 태민 "검사 중에?!"**는 ep02 P34 "연애도 검사받냐!"의 ហ្អេស 어감을 이어 កំពុងឆែកផងហ្អេស?!.
- **글자 없는 쪽지:** P53 도하가 쓴 내용은 그림·대사 어디에도 없다. 평평한 사각 접기는 지문(그림)으로만, 대사로 짚지 않음(ep05 하람 회수용).
