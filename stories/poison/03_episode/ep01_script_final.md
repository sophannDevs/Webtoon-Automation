## ① 콜드 오픈 (P01–P04) · L1 시식방 · 1일째 아침 · 긴장 6

### P01 · 큰 컷(세로 미디엄 와이드) · L1 · 1일째 아침 ⟨복선: 제목 동사⟩
(낮은 옻칠 아침상 앞에 무릎 꿇은 채령이 숟가락을 든다. 상 건너편 방석에 겁먹은 왕자, 곁에 나무 호랑이. 은침 받침 · 향로 · 흰 기미 그릇이 한 화면에. 왼쪽 창호지로 낮고 옅은 아침빛.)
채령: "독이면 제가 먼저 죽습니다."
KM: ឆែរ៉ុង៖ "បើមានពុល ខ្ញុំម្ចាស់ភ្លក់មុន ស្លាប់មុន។"
채령: "그게 제 일이에요."
KM: ឆែរ៉ុង៖ "នេះជាការងាររបស់ខ្ញុំម្ចាស់។"

### P02 · 미디엄 · L1 — 무대사
(전경에 향로, 쑥 향 한 대가 막 연기를 올린다. 뒤로 채령이 작은 국자로 국그릇 **가운데**에서 떠 기미 그릇에 덜어 먹는다. 국자 끝이 가운데에만 닿는다.)
— 무대사 —

### P03 · 투샷 + 향 꽁초 인서트 · L1
(향이 다 타 재가 툭 떨어진다. 채령은 멀쩡하다. 왕자의 어깨가 풀리고, 호랑이를 쥔 손이 느슨해진다.)
채령: "드셔도 됩니다, 왕자 마마."
KM: ឆែរ៉ុង៖ "សូមសោយបានហើយ ព្រះអង្គម្ចាស់។"

### P04 · 미디엄(정면) · L1 ⟨복선 M1⟩
(왕자가 숟가락을 들었다 내려놓고, 그릇을 두 손으로 들어 테두리에 입을 대고 후루룩 마신다. 채령이 난감하게 웃는다.)
채령: "숟가락으로 드셔야지요."
KM: ឆែរ៉ុង៖ "សូមប្រើស្លាបព្រាផង ព្រះអង្គ។"
왕자: "이게 더 맛있어."
KM: ព្រះអង្គម្ចាស់៖ "ផឹកអីចឹង ឆ្ងាញ់ជាង!"

## ② 일상 · 비밀 · 단서 A · B (P05–P12) · L2 회랑 · 1일째 아침 · 긴장 4–5

### P05 · 와이드(기준 앵글 R) · L2 · 아침
(회랑 마루. 기둥 하나가 화면을 세로로 가른다. 뒤로 숙소 창호지 문들, 처마에 꺼진 등롱, 기둥에 빈 당번 판. 민 상궁이 채령의 붉은 댕기를 고쳐 맨다. 맑은 연청 빛, 긴 그림자.)
민 상궁: "댕기가 또 풀렸구나, 얘야."
KM: មីន៖ "ខ្សែបូសក់រលុងទៀតហើយ កូន។"

### P06 · 클로즈업(손 + 채령 옆얼굴) · L2 ⟨복선 A-냄새①⟩
(댕기를 매는 상궁의 손. 고개 숙인 채령이 코끝을 살짝 든다.)
채령: "마마님 손에서… 쓴 냄새가 나요."
KM: ឆែរ៉ុង៖ "ដៃលោកស្រី… មានក្លិនល្វីង។"

### P07 · 바스트(정면 약간 위) · L2 ⟨이중의미 D3⟩
(상궁의 온화한 미소. 눈이 가늘게 접힌다.)
민 상궁: "코는 여전하구나, 얘야."
KM: មីន៖ "ច្រមុះនៅតែមុតដដែល កូន។"

### P08 · 손 클로즈업(R 손 컷 = P50 구도) · L2 ⟨복선 A-시각①⟩ ⟨이중의미 D4⟩
(상궁이 연청 손수건으로 손가락을 닦는다. 모서리에 작은 연보랏빛 얼룩. 프레임 중심은 손, 얼룩은 주인공이 아니게.)
민 상궁: "해독환을 빚었단다."
KM: មីន៖ "ទើបផ្សំថ្នាំបន្សាបពុលរួច។"
민 상궁: "쓴 걸 만지는 게 내 일이지."
KM: មីន៖ "ប៉ះរបស់ល្វីង ជាការងាររបស់ខ្ញុំ។"

### P09 · 당번 판 클로즈업 · L2 ⟨복선 B①⟩
(상궁의 손이 연두 끈 빈 패를 위 고리에서 가운데 고리로 옮겨 건다. 다른 색 끈 패들은 그대로. 판과 패에 글자 없음.)
민 상궁: "내일 점심엔 감찰 나리가 배석하신다."
KM: មីន៖ "ថ្ងៃត្រង់ស្អែក លោកអធិការនឹងមកអង្គុយមើល។"

### P10 · 투샷 미디엄 · L2 ⟨복선 B①⟩ ⟨이중의미 D1⟩
(상궁이 채령의 어깨를 토닥인다. 배려하는 얼굴.)
민 상궁: "왕자 마마는 너 없인 숟가락을 안 드시지."
KM: មីន៖ "បើគ្មានកូន ព្រះអង្គម្ចាស់មិនព្រមសោយទេ។"
민 상궁: "꼭 네가 시식해라."
KM: មីន៖ "ត្រូវតែកូនជាអ្នកភ្លក់ណា។"

### P11 · 노리개 클로즈업 + 원경 뒷모습 · L2 — 무대사
(상궁이 회랑 끝으로 멀어진다, 자두색 뒷모습이 흐리게. 채령의 손이 허리 오른쪽 옥빛 나비 노리개를 꼭 쥔다.)
— 무대사 —

### P12 · 얼굴 미디엄 · L2 · 아침 · (아래 긴 여백: 하루 점프)
(기둥에 기대 혼자 선 채령. 노리개를 쥔 채 눈을 내린다. 등롱은 꺼져 있다.)
채령(생각): "언니, 오늘도 언니 이름으로 살아남았어."
KM: ឆែរ៉ុង (គិត)៖ "បង… ថ្ងៃនេះ ខ្ញុំនៅរស់បានទៀត ក្រោមឈ្មោះបង។"
채령(생각): "채령이는… 아직 아무도 몰라."
KM: ឆែរ៉ុង (គិត)៖ "ឆែរ៉ុង ឈ្មោះពិតខ្ញុំ… មិនទាន់មាននរណាដឹងទេ។"

> 시간 캡션: **넣지 않는다.** P12 아래 긴 여백 + 빛(아침 → 한낮) + 점심 수라상 + 문가의 감찰 + 새 향 + P13 홍 숙수 대사(«លោកអធិការ…មក»)가 P09 «លោកអធិការនឹងមក»를 받는 것으로 충분하다(비트시트 §3).

## ③ 균열 + 법도 선고 (P13–P18) · L1 시식방 · 2일째 점심 · 긴장 6 → 7

홍 숙수: "왕자 마마 국은 내가 직접 끓이고 직접 펐어."
KM: ហុង៖ "ស៊ុបព្រះអង្គម្ចាស់ ខ្ញុំស្ងោរផ្ទាល់ ដួសផ្ទាល់!"
홍 숙수: "식기 전에 드시게 해!"
KM: ហុង៖ "ឯង! ឲ្យទ្រង់សោយ មុនវាត្រជាក់!"

KM: ប៉ែក៖ "នៅតែពណ៌ប្រាក់។"

### P16 · 국 표면 익스트림 클로즈업(채령 시선) · L1 ⟨복선⟩

채령(생각): "…?"

### P17 · 로우앵글 미디엄 · L1

- **미니 반전 ④ (P20–P24):** 복선 P02 · P14(국자 · 은침은 가운데만), P04(왕자가 테두리에 입을 댐) → P21 «មិនមែនកណ្ដាលទេ។ គឺមាត់ចាន។» → P24 «ឥឡូវញ៉ាំបានហើយ?»(P03 «សោយបានហើយ»를 아이 말로 되받아 "이제 먹어도 된다"는 신호가 독의 통로가 된다). 세 박자(위치 → 은침의 한계 → 정체 딜레마)가 생각 말풍선 4개로 분명하다. 너무 빠르지 않음(P19 "괜찮은데…"가 한 박자 지연).
- **주력 반전 ⑧ (P49–P55):** 시각 단서 A(P08 → P29 같은 색 → P50) + 냄새 A(P06 → P20 → P49, 모두 ល្វីង) + B(P09 · P10 → P55, 핵심어 ត្រូវតែកូនជាអ្នកភ្លក់ 글자 그대로 반복) + C(P31 → P54 대사). 주력 공개 전에 단서 4개가 모두 P32 이전에 나왔다 = 공정. P52 · P53 공개 대사는 짧고 분명해 "누가 · 무엇을 · 왜"가 세 풍선 안에 다 있다. 모호하지 않음.
- **클리프행어 ⑨:** 이름(P56, 진짜 이름이 말풍선에 나오는 두 번째 · 마지막) → 침묵 → 명령 2단(P58 · P59). 상궁 말투는 ⑦과 같은 어미(…កូន / …ណា)로, 차갑게 바꾸지 않았다.
- **미스디렉션:** 홍 숙수(P13 «ដួសផ្ទាល់» → P37 같은 낱말로 감찰이 되받음 → P43 연행) → 감찰(P17–18, P41) → 상궁은 끝까지 다정. P38 "국자는 가운데만"이 RH 속 진짜 단서로 남는다.
- twist-patterns §4 자가검증: 반전 2개(미니 · 주력) ✓ · 복선 회차 안 심김 ✓ · 사후 필연성 ✓ · world/characters 모순 없음 ✓ · 대가(침묵 명령 · 매일 시식) ✓ · 미스디렉션 작동 ✓ · 미회수 복선(P11 노리개, P31 소매, P33 두 열쇠 서랍, P22 아버지)은 twist-plan §5에 기록된 다음 회차 몫.

### 3. 수정 목록 (초고 대비)

**구조 · 말풍선 분할 (letterer read_order용)**
- P01: 한 문장 → 두 풍선("독이면 제가 먼저 죽습니다." / "그게 제 일이에요."). 한국어 문장은 concept 고정 그대로, 마침표에서만 나눔.
- P08: 한 줄 → 두 풍선(해독환 / 쓴 걸 만지는 게 내 일).
- P13: 홍 숙수 둘째 풍선(크메르어 약 70자, 3줄)을 둘로 나눔 → P13은 **3풍선(read_order 1 · 2 · 3)**. 이 회차의 유일한 3풍선 패널이며, characters §5-6 "홍 숙수는 짧게 끊어 여러 말풍선으로 쏟아낸다"를 따른 것. 와이드 컷이라 자리 충분. 자리가 모자라면 letterer는 3번 풍선을 지울 수 있다(대체 불가 정보 없음).
- P28: 둘째 문장(크메르어 약 55자)을 줄여 2줄 이내로.
- 모든 풍선이 크메르어 31 글자 묶음(자음 + 딸린 모음 · 받침 기준, 코드포인트 51) 이하 = 약 2줄. 최장 P28 둘째 풍선 · P32(각 31묶음), 다음 P23 · P36 · P34(28묶음).

**크메르어 자연스러움 · 명료성**
- P03: «សូមព្រះអង្គសោយចុះ ព្រះអង្គម្ចាស់» → «សូមសោយបានហើយ ព្រះអង្គម្ចាស់» (ព្រះអង្គ 중복 제거, P24와 "បានហើយ" 메아리).
- P04: 채령 «សោយនឹងស្លាបព្រា» → «សូមប្រើស្លាបព្រាផង ព្រះអង្គ» / 왕자 «ធ្វើអីចឹង» → «ផឹកអីចឹង»(후루룩 마시는 동작과 일치).
- P08: លាយថ្នាំ(섞다) → ផ្សំថ្នាំ(약을 짓다, 전통 약 조제에 쓰는 말).
- P09: «…មកអង្គុយមើលផង» → «…នឹងមកអង្គុយមើល» (미래 표지 នឹង, ផង 남용 정리 — ផង은 P04 · P59에 남김).
- P12: «…ក្នុងឈ្មោះបង» → «…ក្រោមឈ្មោះបង»(남의 이름 "아래" 사는 것), 둘째 생각 «ឆែរ៉ុង… នៅគ្មាននរណាដឹងទេ» → «ឆែរ៉ុង ឈ្មោះពិតខ្ញុំ… មិនទាន់មាននរណាដឹងទេ». 크메르어 독자에게 ឆែរ៉ុង이 "그녀의 진짜 이름"임이 처음이자 유일하게 확실히 전달되는 곳이라, 이름 뒤에 ឈ្មោះពិតខ្ញុំ을 붙였다(P56 충격의 전제). 한국어는 그대로.
- P13 · P37: "직접" ខ្លួនឯង / ផ្ទាល់ → ផ្ទាល់로 통일. 3인칭 왕자는 ទ្រង់(용어집 추가).
- P17 · P18: «…ដែលរំលងពុល»(건너뛰다) → «…ដែលរកពុលមិនឃើញ»(독을 찾지 못한), «…ប្ដឹងពុលមិនពិត» → «…ប្ដឹងពុលដែលគ្មាន»(없는 독). 두 줄이 "못 찾은 / 없는" 짝으로 선다.
- P19: ប៉ុន្តែ → តែ (생각 말풍선 구어).
- P22: «សម័យប៉ា»(아버지 시대) → «រឿងប៉ាពីមុន»(예전 아버지 일).
- P23: និយាយ → និយាយចេញ ("뱉다" 뉘앙스, P46 "삼키다"와 대비).
- P25: «សូមរង់ចាំ!»(격식, 느림) → «សូមចាំសិន!»(급히 멈추는 말).
- P26 (고변 고정 문구): «សូមដកតុព្រះស្ងោយចេញ» → «សូមលើកព្រះស្ងោយចេញ» (상을 "치우다"는 លើក…ចេញ이 자연스럽다). 용어집 고정 문구도 같이 바꿈. 매 회차 같은 문장.
- P28: 첫 문장에 នេះជា(보고체 "~입니다"), 둘째 문장 끝 ចេញពណ៌ពិត("제 색 = 참된 색" — 채령 자신의 정체 드러남과도 겹침).
- P31 효과음: ហឹក!(크메르어에서 흐느낌 소리) → អា៎!(놀람). **[감수]**
- P34: វិធី → ល្បិច("수법", 약간 수상쩍은 뉘앙스), «…ពីណា» → «…មកពីណា».
- P36: ការងារតូចតាច → ការតូចតាច(짧게).
- P38: 생각 끝 «…ទេតើ» → «…ទេ…»(문법 정리, 여운).
- P40: «ទីនេះ ហាមចូល» → «ទីនេះ ជាកន្លែងហាមចូល»(감찰의 딱딱한 존대).
- P45: «មេចុងភៅ… មិនមែនទេ»("숙수는… 아니에요"가 크메르어에선 무엇이 아닌지 모호) → «មេចុងភៅ… មិនមែនជាអ្នកធ្វើទេ»(범인이 아니다).
- P46: «ល្វីងក៏ត្រូវលេប…» → «របស់ល្វីង ក៏ត្រូវលេប…»(D4와 같은 낱말).
- P53: «ខ្ញុំកំពុងរកក្មេង ដែលស្គាល់វា» → «ខ្ញុំកំពុងរកក្មេងម្នាក់ ដែលមើលវាដឹង»(위 점검표 "은이 못 보는").
- P54: «គេទាំងអស់មើលព្រះអង្គម្ចាស់។ ខ្ញុំមើលកូន។» → «គ្រប់គ្នាមើលតែព្រះអង្គម្ចាស់។ ខ្ញុំ… មើលកូន។»
- P55: D1 반복 맞춤(위 표), 생각 «គាត់ដាក់នុយ… ចាប់ខ្ញុំ» → «គាត់ដាក់នុយ… ស្ទូចខ្ញុំ»(ស្ទូច = 낚싯바늘로 낚다).
- 한국어 대사는 바꾸지 않았다(분할만). P32 조정안("기미의 혀")은 초고 판단을 채택: P20 냄새 발견과 모순 없고, ⑨ "입을 다물고"의 표적이 된다.
