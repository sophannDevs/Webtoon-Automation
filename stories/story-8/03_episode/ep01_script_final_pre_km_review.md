- P35 삼촌 긴 대사를 말풍선 2개로 분할: 「1일에 모자랐던 거, 그쪽에서 급하대.」(`…ខាងនោះគេប្រញាប់ណា៎។` — 삼촌의 부드러운 `ណា៎` 추가) / 「삼촌이 할 얘기도 있고.」(`ពូមានរឿងចង់និយាយជាមួយឯងផង។`). 판정 G(저녁 호출 이유)와 E01-G `ខាងនោះគេ` 유지. 한 패널 말풍선 = 삼촌 2 + 하린 1 → letterer는 3개 배치 필요(또는 하린 줄을 하단에).
- P50 「다음 달 거.」 → 「다음 달 봉투다.」 / KM `ស្រោមសំបុត្រខែក្រោយ។ នៅមានពូទេតើ ក្មួយ។`. 봉투 문법(낸 사람 = 납작한 빈 봉투를 받아 간다)을 크메르어 독자에게 명시해 P58 우진의 빈 봉투가 "오늘 냈다"로 바로 읽히게 했다. 삼촌 말투의 `ក្មួយ` 추가.
- 그 밖의 대사는 초고 유지: 말투가 이미 뚜렷하다(하린 짧고 공손 / 인호 1–4어절 / 미자 감탄사·`ណា៎` / 우진 퉁명 `ខ្ញុំ` / 새롬 `អូន`·장난 어미 / 석구 `ក្មួយ`·`ណា៎`, P46만 어미 없음).

**반전 명료성 판정: PASS** (이미지 + 크메르어 말풍선만 보는 독자 기준)
- 사슬 ① 말: P35 `អ៊ូជីន ឬម៉ែ` → P36 `ប្អូនឯង … គ្មាននរណាដឹងទេ` → P37 `ដឹងតែឯងនឹងពូ` (T1, 제목 `ដឹងតែយើងពីរនាក់`과 같은 뜻) → P52 `វា` + `ក៏…ដែរ` + `ទាន់ថ្ងៃ` + `ហើយ` + `—` → P54 `អ្នកណា?` → P56 `ក្មេងក្នុងភូមិ`(해명이 "어린 사람"을 다시 확인). P36 `ប្អូនឯង` ↔ P52 `វា` 호칭 전환이 같은 화자·같은 대상으로 16패널 간격 — 대비 성립.
- 사슬 ② 물건: P19 팔찌(우진 손목) → P20 `មិនលក់ដាច់ខាត` → P21 덮는 손 → P48 서랍 팔찌(같은 각도) → P52 "걔도 냈다".
- 사슬 ③ 봉투: P10–13 돈 넣는 봉투 → P50 납작한 빈 봉투 `ស្រោមសំបុត្រខែក្រោយ` → P52 완료형 `…ហើយ` → P58 우진 패딩에서 같은 접힘의 납작한 봉투 = 우진도 오늘 냈다. 대사 없이 결론 도달.
- 사슬 ④ 패딩: P27·P32 의자 → P41 노을 원경 → P57 현관.
- 작은 승리: P38 `ក្មួយនឹងប្រយ័ត្ន` → P45 `ខ្ញុំឲ្យបានប៉ុណ្ណឹងទេ ពូ` → P46 `ប៉ុណ្ណឹង?`(차가운 메아리). 대비 유지.
